# Truck Electrical Bench

A phone-friendly trainer for heavy-truck electrical diagnosis. Every sheet is a live 12 V circuit: put the multimeter leads on any test point, flip switches and module outputs, and hunt random or self-planted faults. After you find a fault it explains what caused it and how to fix it properly.

## Features
- 118 wiring sheets modelled as circuits (power distribution, grounds, starting, engine, transmission, ABS, lighting, sleeper, trailer, CAN data links)
- Multimeter with DC volts and ohms (ohms = battery disconnected)
- Faults: open, high resistance / corrosion, short to ground, stuck-on / welded, internal short, bad ground points, missing CAN terminators
- Driver-style complaints generated by the simulator (dead/dim loads, blown fuses, relays not clicking, scan-tool live data, data link errors)
- Cause and proper repair shown after each correct call
- Parts finder for the schematic's parts index
- Works offline as one HTML file; progress is saved in the browser

## Run it
Open `docs/index.html` in any browser. No install needed.

## Publish on GitHub Pages
1. Push this repo to GitHub.
2. Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/docs`.
3. The site appears at `https://<your-user>.github.io/truck-electrical-bench/`.

## Develop
```
src/page.html      markup and styles
src/ui.js          drawing, meter, jobs, events
src/engine.js      circuit model, nodal solver, symptoms, fault causes
src/data/s01–s38   circuit data, one file per three sheets
src/data/zidx.js   parts index
build.py           bundles everything into docs/index.html
tests/sim-test.js  runs every possible fault on every sheet
```
After editing `src/`, run `python3 build.py` (or `npm run build`) and commit `docs/index.html` too.
`npm test` prints, per sheet, how many faults produce a symptom, plus any sanity problems.

### Circuit data format
Each sheet is a list of columns. A column starts at a feed (`B` battery, `I` ignition, `5` ECU 5 V, `C` CAN bias, `S` battery with internal resistance, `A` 120 V AC, or `[col,node]` to tap another column), runs through items, and ends at `N` (battery −), `G:NAME` (a ground point), `[col,node]`, or `null` (open end).
Item = `[type, tag, name, value]`. Types: `w` wire (gauge read from the tag), `k` connector/splice/stud, `f` fuse (amps), `cb` breaker, `sw` switch, `ecu` module output, `rk`/`rc`/`rn` relay coil / N.O. / N.C. contacts, `L`/`D` lamp/LED (watts), `M` `H` `S` `X` `E` motor, horn/speaker, solenoid, heater, module (amps), `R` resistor/sensor (Ω), `Q` module input (Ω), `T` CAN terminator, `ri` battery internal resistance.

## Important
This is a learning tool. The circuits are simplified from the source schematic. Always use the manufacturer's service information on a real truck.
